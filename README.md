# NGVT
Nonlinear Geometric Vortexing Torus: A Robust AI Architecture for Quantum and Autonomous Systems

## Quick Start

### Command Line Interface
Generate code instantly from the command line:

```bash
cd torusScode
python3 ngvt-cli.py "Write a function to calculate factorial"
python3 ngvt-cli.py --interactive  # Interactive mode
python3 ngvt-cli.py --list-templates  # See available templates
```

See [CLI-README.md](torusScode/CLI-README.md) for detailed usage.

### Web Interface
The system also includes a web interface at `torusScode/web/index.html`.
